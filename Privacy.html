[ Phone / Tablet & Android TV/Box Versions ]
နောက်ဆုံးပြင်ဆင်သည့်ရက်စွဲ: August 2026

BFA STREAM သည် အသုံးပြုသူများ၏ သီးသန့်လုံခြုံရေးနှင့် ကိုယ်ရေးအချက်အလက်များကို အလေးထားစောင့်ရှောက်ပါသည်။ ဤ Privacy Policy သည် ကျွန်ုပ်တို့၏ Mobile Version (Phone/Tablet) နှင့် Android TV / Box Version အသုံးပြုသူများထံမှ အချက်အလက်များ စုဆောင်းပုံ၊ အသုံးပြုပုံနှင့် ကာကွယ်စောင့်ရှောက်ပုံများကို ရှင်းလင်းဖော်ပြထားခြင်း ဖြစ်သည်။

၁။ စုဆောင်းသော အချက်အလက်များ (Information We Collect)

BFA STREAM သည် အသုံးပြုသူများ၏ ကိုယ်ရေးကိုယ်တာ အချက်အလက် (အမည်၊ နေရပ်လိပ်စာ) များကို တောင်းခံခြင်း သို့မဟုတ် သိမ်းဆည်းခြင်း ပြုလုပ်မည်မဟုတ်ပါ။ App ပေါ့ပါးစွာ လည်ပတ်နိုင်ရေးအတွက် အောက်ပါ နည်းပညာဆိုင်ရာ အချက်အလက်အချို့ကိုသာ အသုံးပြုနိုင်ပါသည် -

  • Device Information: Android OS Version၊ Device Model (ဖုန်း၊ Tablet သို့မဟုတ် Android TV/Box) နှင့် Screen Resolution စသည်တို့ ဖြစ်သည်။
  • App Usage & Preference: Modern Version သို့မဟုတ် Static HTML (OLD Version) ရွေးချယ်သုံးစွဲမှုနှင့် Error Logs များ။
  • Network Status: အင်တာနက်ချိတ်ဆက်မှု အခြေအနေ (Streaming အဆင်ပြေစေရန်အတွက် ဖြစ်သည်)။

၂။ အချက်အလက်များ အသုံးပြုပုံ (How We Use Information)

စုဆောင်းရရှိသော နည်းပညာဆိုင်ရာ အချက်အလက်များကို အောက်ပါနေရာများတွင်သာ သီးသန့်အသုံးပြုပါသည် -

  • Mobile နှင့် Android TV/Box များပေါ်တွင် Streaming ထိရောက်စွာ လည်ပတ်နိုင်ရန်။
  • Device အဟောင်းများနှင့် အင်တာနက်လိုင်းနိမ့်သူများအတွက် Static HTML Version သို့ ပေါ့ပါးစွာ ချိတ်ဆက်ပေးနိုင်ရန်။
  • App အတွင်း ဖြစ်ပေါ်တတ်သော Error များကို ပြင်ဆင်စောင့်ရှောက်ရန်။

၃။ App Permissions (လိုအပ်သော ခွင့်ပြုချက်များ)

BFA STREAM ကို အသုံးပြုရန် အောက်ပါ Standard Permissions များသာ လိုအပ်ပါသည် -

  • INTERNET : Live Streaming ဗီဒီယိုများနှင့် အချက်အလက်များ ရယူရန်။
  • ACCESS_NETWORK_STATE : အင်တာနက်လိုင်း ချိတ်ဆက်ထားမှုကို စစ်ဆေးရန်။
  • WAKE_LOCK : Android TV / Mobile များတွင် ဗီဒီယိုကြည့်နေစဉ် မျက်နှာပြင် အလိုအလျောက် ပိတ်မသွားစေရန်။

၄။ အချက်အလက် မျှဝေခြင်း (Data Sharing)

ကျွန်ုပ်တို့သည် သုံးစွဲသူများ၏ မည်သည့် အချက်အလက်ကိုမျှ ပြင်ပကုမ္ပဏီ သို့မဟုတ် လူပုဂ္ဂိုလ်များထံ ရောင်းချခြင်း၊ ငှားရမ်းခြင်း သို့မဟုတ် လွှဲပြောင်းမျှဝေခြင်း လုံးဝ မပြုလုပ်ပါ။

၅။ ကလေးသူငယ်များ လုံခြုံရေး (Children's Privacy)

BFA STREAM သည် အသက် ၁၃ နှစ်အောက် ကလေးသူငယ်များ၏ မည်သည့် ကိုယ်ရေးအချက်အလက်ကိုမျှ ရည်ရွယ်ချက်ရှိရှိ စုဆောင်းခြင်း မရှိပါ။
